# 部署说明

## 📦 部署包内容

1. **Docker镜像文件**
   - `yudao-admin.tar` - 前端镜像
   - `yudao-server.tar` - 后端镜像

2. **配置文件**
   - `docker-compose.prod.yml` - Docker Compose配置
   - `.env.example` - 环境变量配置示例

## 🚀 部署步骤

### 1. 上传文件到服务器

```bash
# 上传整个部署包目录到服务器
scp -r deploy/packages/YYYYMMDD user@server:/path/to/deploy/
```

### 2. 准备环境变量文件

```bash
cd /path/to/deploy/YYYYMMDD
cp .env.example .env
# 编辑 .env 文件，设置以下关键配置：
# - MYSQL_ROOT_PASSWORD: 数据库root密码
# - MASTER_DATASOURCE_PASSWORD: 主数据源密码
# - SLAVE_DATASOURCE_PASSWORD: 从数据源密码
# - REDIS_PASSWORD: Redis密码
```

### 3. 导入Docker镜像

```bash
cd /path/to/deploy/YYYYMMDD
docker load -i yudao-admin.tar
docker load -i yudao-server.tar
```

### 4. 启动服务

```bash
cd /path/to/deploy/YYYYMMDD
docker-compose -f docker-compose.prod.yml --env-file .env up -d
```

### 5. 检查服务状态

```bash
# 查看容器状态
docker ps

# 查看日志
docker logs yudao-server-prod
docker logs yudao-admin-prod

# 查看网络
docker network inspect erp-network
```

## ⚠️ 注意事项

1. **端口开放**
   - 确保服务器防火墙开放端口：80（前端）、48080（后端）

2. **数据库初始化**
   - 首次部署需要执行SQL初始化脚本
   - SQL文件位置：`sql/mysql/ruoyi-vue-pro.sql`

3. **环境变量**
   - 必须设置强密码
   - 不要将 `.env` 文件提交到版本控制

4. **数据持久化**
   - MySQL数据存储在Docker volume: `mysql_data`
   - Redis数据存储在Docker volume: `redis_data`

## 🔍 故障排查

### 前端无法访问后端API
- 检查nginx配置：`docker exec yudao-admin-prod cat /etc/nginx/conf.d/default.conf`
- 检查后端容器是否运行：`docker ps | grep yudao-server-prod`

### 后端无法连接数据库
- 检查数据库容器状态：`docker ps | grep mysql`
- 检查环境变量：`docker exec yudao-server-prod env | grep DATASOURCE`

### 查看详细日志
```bash
# 后端日志
docker logs -f yudao-server-prod

# 前端日志
docker logs -f yudao-admin-prod

# 数据库日志
docker logs -f yudao-mysql-prod
```
