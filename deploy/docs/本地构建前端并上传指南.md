# 本地构建前端镜像并上传到服务器指南

## 📋 前置要求

1. **本地已安装 Docker 和 Docker Compose**
2. **本地有项目代码**（已修改的前端代码）
3. **SSH 密钥**：`/Users/xierui/Documents/Project/Other/erp-system/tengxunyun.pem`

## 🚀 完整操作步骤

### 步骤1: 本地构建前端镜像

在项目根目录执行：

```bash
# 进入项目目录
cd /Users/xierui/Documents/Project/Other/erp-system

# 给脚本添加执行权限（如果还没有）
chmod +x deploy/scripts/build-frontend-local.sh

# 执行构建脚本
./deploy/scripts/build-frontend-local.sh
```

**预计时间：**
- 首次构建：5-10 分钟
- 增量构建（仅代码变化）：30秒-2分钟

### 步骤2: 导出镜像

构建成功后，导出镜像：

```bash
# 给脚本添加执行权限
chmod +x deploy/scripts/export-frontend-image.sh

# 执行导出脚本
./deploy/scripts/export-frontend-image.sh
```

镜像会导出到：`deploy/exports/frontend-image-YYYYMMDD-HHMMSS.tar.gz`

### 步骤3: 上传镜像到服务器

**方法A：使用上传脚本（推荐）**

```bash
# 给脚本添加执行权限
chmod +x deploy/scripts/upload-frontend-image.sh

# 执行上传脚本（会自动找到最新的镜像文件）
./deploy/scripts/upload-frontend-image.sh
```

**方法B：手动上传**

```bash
# 找到最新的镜像文件
LATEST_IMAGE=$(ls -t deploy/exports/frontend-image-*.tar.gz | head -1)

# 上传到服务器
scp -i /Users/xierui/Documents/Project/Other/erp-system/tengxunyun.pem \
  "$LATEST_IMAGE" \
  ubuntu@101.33.244.240:/tmp/
```

### 步骤4: 在服务器上导入镜像并重启服务

SSH到服务器并执行：

```bash
# 连接服务器
ssh -i /Users/xierui/Documents/Project/Other/erp-system/tengxunyun.pem ubuntu@101.33.244.240

# 进入项目目录
cd /opt/erp-system/script/docker

# 找到上传的镜像文件
LATEST_IMAGE=$(ls -t /tmp/frontend-image-*.tar.gz | head -1)

# 导入镜像
gunzip -c "$LATEST_IMAGE" | docker load

# 删除临时文件（可选）
rm -f "$LATEST_IMAGE"

# 重启前端服务
docker-compose -f docker-compose.prod.yml --env-file .env up -d --force-recreate admin

# 检查服务状态
docker-compose -f docker-compose.prod.yml ps

# 查看日志
docker-compose -f docker-compose.prod.yml logs -f admin
```

## 🔧 一键执行脚本

你也可以创建一个一键脚本，自动完成所有步骤：

```bash
#!/bin/bash
# 一键构建、导出、上传、部署前端

set -e

PROJECT_DIR="/Users/xierui/Documents/Project/Other/erp-system"
cd "$PROJECT_DIR"

echo "=== 步骤1: 构建前端镜像 ==="
./deploy/scripts/build-frontend-local.sh

echo ""
echo "=== 步骤2: 导出镜像 ==="
./deploy/scripts/export-frontend-image.sh

echo ""
echo "=== 步骤3: 上传镜像 ==="
LATEST_IMAGE=$(ls -t deploy/exports/frontend-image-*.tar.gz | head -1)
scp -i tengxunyun.pem "$LATEST_IMAGE" ubuntu@101.33.244.240:/tmp/

echo ""
echo "=== 步骤4: 在服务器上导入并重启 ==="
IMAGE_NAME=$(basename "$LATEST_IMAGE")
ssh -i tengxunyun.pem ubuntu@101.33.244.240 << EOF
cd /opt/erp-system/script/docker
gunzip -c /tmp/$IMAGE_NAME | docker load
rm -f /tmp/$IMAGE_NAME
docker-compose -f docker-compose.prod.yml --env-file .env up -d --force-recreate admin
docker-compose -f docker-compose.prod.yml ps
EOF

echo ""
echo "✅ 部署完成！"
```

## ⚠️ 注意事项

1. **镜像大小**：前端镜像通常 100-300MB，上传需要一些时间
2. **网络速度**：上传速度取决于你的网络带宽
3. **服务器空间**：确保服务器 `/tmp` 目录有足够空间（至少 500MB）
4. **权限问题**：确保 SSH 密钥权限正确：`chmod 600 tengxunyun.pem`
