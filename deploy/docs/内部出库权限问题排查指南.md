## 🔧 排查步骤

### 步骤1: 清除浏览器缓存（最重要！）

**方法1: 清除特定网站缓存**
1. 打开浏览器开发者工具（F12）
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"

**方法2: 清除所有缓存**
- **Chrome/Edge**: 
  - 设置 → 隐私和安全 → 清除浏览数据
  - 选择"缓存的图片和文件"、"Cookie和其他网站数据"
  - 时间范围选择"全部时间"
  - 点击"清除数据"

- **Firefox**:
  - 设置 → 隐私与安全 → Cookie和网站数据
  - 点击"清除数据"

### 步骤2: 完全退出并重新登录

1. **退出登录**
   - 点击右上角用户头像
   - 选择"退出登录"

2. **关闭浏览器**
   - 完全关闭所有浏览器窗口
   - 确保浏览器进程完全退出

3. **重新打开浏览器并登录**
   - 访问: http://101.33.244.240
   - 使用admin账号登录
   - 登录后系统会自动获取最新权限

### 步骤3: 检查浏览器控制台

1. 打开开发者工具（F12）
2. 查看Console标签页
   - 是否有权限相关的错误信息
   - 是否有JavaScript错误

3. 查看Network标签页
   - 找到 `/admin-api/system/auth/get-permission-info` 请求
   - 查看响应中是否包含 `erp:stock:internal-out:query` 等权限

### 步骤4: 手动刷新权限（如果上述方法无效）

在浏览器控制台执行以下代码：

```javascript
// 清除用户缓存
localStorage.removeItem('user')
sessionStorage.removeItem('user')

// 重新获取用户信息
// 需要先登录，然后刷新页面
location.reload()
```

## 🔍 验证权限是否生效

### 方法1: 通过浏览器控制台检查

打开浏览器控制台（F12），执行：

```javascript
// 检查当前用户权限
const userStore = window.__PINIA_STORE__?.adminUser || {}
console.log('用户权限:', userStore.permissions)
console.log('是否有内部出库权限:', userStore.permissions?.has('erp:stock:internal-out:query'))
```

### 方法2: 通过数据库验证

```sql
-- 检查admin用户的所有角色是否有内部出库权限
SELECT 
    u.username,
    r.id as role_id,
    r.name as role_name,
    COUNT(DISTINCT rm.menu_id) as internal_out_permissions
FROM system_users u
JOIN system_user_role ur ON u.id = ur.user_id
JOIN system_role r ON ur.role_id = r.id
LEFT JOIN system_role_menu rm ON r.id = rm.role_id
    AND rm.menu_id IN (SELECT id FROM system_menu WHERE permission LIKE '%internal-out%')
WHERE u.username = 'admin'
GROUP BY u.username, r.id, r.name;
```

## ⚠️ 常见问题

### 问题1: 清除缓存后仍然没有权限

**可能原因**:
- 用户当前使用的角色没有权限
- 权限API返回的数据不正确

**解决方法**:
1. 检查当前登录用户使用的角色
2. 确认该角色在数据库中有内部出库权限
3. 重新登录系统

### 问题2: 部分功能有权限，部分没有

**可能原因**:
- 权限按钮（如创建、更新、删除）没有分配

**解决方法**:
- 检查数据库中是否有所有权限按钮的配置
- 确保角色拥有所有相关权限

### 问题3: 权限时有时无

**可能原因**:
- Redis缓存问题
- 浏览器缓存问题

**解决方法**:
1. 重启Redis服务
2. 重启后端服务
3. 清除浏览器缓存
4. 重新登录

## 📝 权限列表

内部出库需要的权限：
- `erp:stock:internal-out:query` - 查询权限（必需）

- `erp:stock:internal-out:delete` - 删除权限
- `erp:stock:internal-out:export` - 导出权限
- `erp:stock:internal-out:approve` - 审批权限
