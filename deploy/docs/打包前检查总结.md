## 📝 下一步操作

1. **准备环境变量文件**
   ```bash
   cd deploy/config
   cp env.prod.example .env
   # 编辑 .env 文件，设置密码等
   ```

2. **构建Docker镜像**
   ```bash
   # 前端
   cd original-yudao-ui
   docker build -t yudao-admin:latest .
   
   # 后端（确保已打包）
   cd yudao-server
   docker build -t yudao-server:latest .
   ```

3. **导出镜像（如需要）**
   ```bash
   docker save yudao-admin:latest -o yudao-admin.tar
   docker save yudao-server:latest -o yudao-server.tar
   ```

4. **上传到服务器**
   - 上传镜像文件
   - 上传配置文件（docker-compose.prod.yml, .env）

5. **在服务器上部署**
   ```bash
   docker load -i yudao-admin.tar
   docker load -i yudao-server.tar
   docker-compose -f docker-compose.prod.yml --env-file .env up -d
   ```
