## 🔍 故障排查

### 前端无法访问
1. 检查nginx容器状态：`docker ps | grep yudao-admin-prod`
2. 查看nginx日志：`docker logs yudao-admin-prod`
3. 检查端口：`netstat -tlnp | grep 80`

### 后端API无法访问
1. 检查后端容器状态：`docker ps | grep yudao-server-prod`
2. 查看后端日志：`docker logs yudao-server-prod`
3. 检查端口：`netstat -tlnp | grep 48080`
4. 检查数据库连接：查看日志中的数据库连接错误

### 数据库连接问题
1. 检查MySQL容器：`docker ps | grep mysql`
2. 检查环境变量：`docker exec yudao-server-prod env | grep DATASOURCE`
3. 测试数据库连接：
   ```bash
   docker exec -it yudao-mysql-prod mysql -uroot -p
   ```
