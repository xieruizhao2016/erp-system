## 🔍 验证方法

### 方法1：通过数据库验证
```sql
SELECT 
    m.id,
    m.name,
    m.permission,
    CASE WHEN rm.role_id IS NOT NULL THEN '有权限' ELSE '无权限' END as status
FROM system_menu m
LEFT JOIN system_role_menu rm ON m.id = rm.menu_id AND rm.role_id = 1
WHERE m.permission LIKE '%internal-out%'
ORDER BY m.id;
```
