# 打包前检查清单

## 📋 检查项概览

### ✅ 1. 前端接口地址配置检查

#### 1.1 环境变量文件检查
**文件位置：** `original-yudao-ui/.env.prod`

**当前配置：**
```bash
VITE_BASE_URL=''              # 空字符串，表示使用相对路径
VITE_API_URL=/prod-api        # API接口路径
```

**检查要点：**
- ✅ `VITE_BASE_URL` 为空字符串，表示使用相对路径（适合通过nginx代理）
- ✅ `VITE_API_URL` 设置为 `/prod-api`，与nginx配置一致
- ⚠️ **注意：** 如果服务器域名不是根路径，需要设置 `VITE_BASE_URL` 为完整域名

#### 1.2 Nginx配置检查
**文件位置：** `original-yudao-ui/nginx.conf`

**关键配置：**
```nginx
location /prod-api {
    rewrite ^/prod-api/(.*) /admin-api/$1 break;
    proxy_pass http://yudao-server-prod:8080;
}
```

**检查要点：**
- ✅ `/prod-api` 路径重写为 `/admin-api`
- ✅ 代理到后端容器 `yudao-server-prod:8080`
- ⚠️ **注意：** 确保后端容器名称与docker-compose配置一致

#### 1.3 Docker Compose配置检查
**文件位置：** `script/docker/docker-compose.prod.yml`

**前端构建参数：**
```yaml
VITE_BASE_URL: ${VITE_BASE_URL:-}          # 默认空
VITE_API_URL: ${VITE_API_URL:-/prod-api}  # 默认 /prod-api
```

**检查要点：**
- ✅ 环境变量可通过 `.env` 文件覆盖
- ✅ 默认值与 `.env.prod` 一致

### ✅ 2. 后端配置检查

#### 2.1 数据库配置
**配置方式：** 通过Docker环境变量传递

**关键配置：**
```yaml
MASTER_DATASOURCE_URL: jdbc:mysql://mysql:3306/ruoyi-vue-pro?...
MASTER_DATASOURCE_USERNAME: root
MASTER_DATASOURCE_PASSWORD: ${MASTER_DATASOURCE_PASSWORD}
```

**检查要点：**
- ⚠️ **必须设置：** `MASTER_DATASOURCE_PASSWORD` 和 `SLAVE_DATASOURCE_PASSWORD`
- ⚠️ **必须设置：** `MYSQL_ROOT_PASSWORD`
- ✅ 数据库连接使用容器名称 `mysql`（Docker网络内）

#### 2.2 Redis配置
**关键配置：**
```yaml
REDIS_HOST: redis
REDIS_PORT: 6379
REDIS_PASSWORD: ${REDIS_PASSWORD:-}
REDIS_DATABASE: 1
```

**检查要点：**
- ⚠️ **建议设置：** `REDIS_PASSWORD`（生产环境必须设置密码）
- ✅ Redis连接使用容器名称 `redis`（Docker网络内）

#### 2.3 后端端口配置
**Dockerfile检查：** `yudao-server/Dockerfile`
- ✅ 暴露端口：`8080`（容器内端口）
- ✅ docker-compose中映射为 `48080:8080`（外部48080映射到容器内8080）
- ✅ `application-prod.yaml` 中配置 `server.port: 8080`
- ⚠️ **注意：** 外部访问使用48080端口，容器内应用运行在8080端口

### ⚠️ 7. 常见问题检查

#### 7.1 接口地址问题
**问题：** 前端无法访问后端API

**检查：**
- ✅ `VITE_API_URL` 是否设置为 `/prod-api`
- ✅ nginx配置是否正确代理 `/prod-api` 到后端
- ✅ 后端容器名称是否为 `yudao-server-prod`
- ✅ 后端容器端口是否为 `8080`（容器内）

#### 7.2 跨域问题
**问题：** 浏览器报CORS错误

**检查：**
- ✅ 后端已配置跨域支持（Spring Boot配置）
- ✅ nginx代理配置正确

#### 7.3 数据库连接问题
**问题：** 后端无法连接数据库

**检查：**
- ✅ 数据库密码是否正确设置
- ✅ 数据库容器名称是否为 `mysql`
- ✅ 数据库连接URL中的数据库名是否正确
- ✅ 网络配置：所有容器在同一Docker网络 `erp-network`

### 📝 8. 部署步骤建议

#### 步骤1：准备环境变量文件
```bash
cd deploy/config
cp env.prod.example .env
# 编辑 .env 文件，设置数据库密码、Redis密码等
```

#### 步骤2：构建Docker镜像
```bash
# 构建前端镜像
cd original-yudao-ui
docker build -t yudao-admin:latest .

# 构建后端镜像
cd yudao-server
mvn clean package -DskipTests
docker build -t yudao-server:latest .
```

#### 步骤3：导出镜像（如果需要）
```bash
docker save yudao-admin:latest -o yudao-admin.tar
docker save yudao-server:latest -o yudao-server.tar
```

#### 步骤4：上传到服务器
```bash
# 上传镜像文件
scp yudao-admin.tar user@server:/path/to/deploy/
scp yudao-server.tar user@server:/path/to/deploy/

# 上传配置文件
scp script/docker/docker-compose.prod.yml user@server:/path/to/deploy/
scp deploy/config/.env user@server:/path/to/deploy/
```

#### 步骤5：在服务器上部署
```bash
# 导入镜像
docker load -i yudao-admin.tar
docker load -i yudao-server.tar

# 启动服务
cd /path/to/deploy
docker-compose -f docker-compose.prod.yml --env-file .env up -d
```
